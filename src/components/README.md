# Components

Componentes reutilizables de interfaz para VNDRX.

- `common/`: botones, tarjetas, modales, estados vacios y piezas generales.
- `navigation/`: cabeceras, menus, tabs y navegacion.
- `products/`: tarjetas de productos, galerias, selectores y cantidades.
- `stores/`: tarjetas y perfiles de tiendas/productores.
- `checkout/`: carrito, resumen, delivery, pagos y confirmacion.
- `dashboard/`: piezas del panel privado o administrador.

Las piezas nuevas deben crearse aqui antes de ampliar `src/VNDRX.jsx`.
