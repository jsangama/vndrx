# Backend VNDRX

Esta carpeta reserva la capa de backend para VNDRX.

Responsabilidades previstas:

- Autenticacion y seguridad.
- Reglas comerciales.
- Pedidos.
- Pagos.
- Integraciones externas.
- WhatsApp.
- Logistica.
- Paneles operativos.
- Analitica.

La app publica actual puede funcionar como frontend estatico, pero la arquitectura queda preparada para mover operaciones criticas a servicios backend independientes.
